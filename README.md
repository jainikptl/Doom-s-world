# 🏰 Doom's World

**The Digital Kingdom of Doctor Doom** — an AI-powered job recruitment and career growth platform.  
This web app combines intelligent matching, resume analysis, mock interviews, and integrated communication tools to help job seekers and recruiters connect faster and more effectively.

🌐 **Live Site:** [doom-s-world.vercel.app](https://doom-s-world.vercel.app)

---

## 🚀 Features

- **🤖 AI-Powered Job Matching**  
  Matches candidates with relevant jobs based on skills, experience, and preferences.

- **📄 Resume Analyzer**  
  AI-driven resume analysis with instant feedback for improvements.

- **🎙 Mock Interviews**  
  Simulated interview sessions with AI to prepare for real-world scenarios.

- **📅 Scheduling Tools**  
  Integrated calendar and one-click scheduling between recruiters and applicants.

- **📹 Video Calling**  
  Seamless, in-app video call support for interviews.

---

## 🛠 Tech Stack

- **Frontend:** Next.js, React.js, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Hosting:** Vercel  
- **AI Integration:** OpenAI API, NLP models
